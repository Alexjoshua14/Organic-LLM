# Noesis

Noesis helps you start and steer a conversation about a topic. Instead of a blank box, it offers openers drawn from how you have talked before.

> **Status:** Noesis is in development and limited to invited accounts, so there is no Open button here.

## What it is for

- **Sparks:** starter prompts and prompts along the thread, generated from your past conversations
- **Suggest my reply:** a draft of your next message from the thread's context, which you edit before sending
- **Steer notes:** small nudges that shape where the thread goes next

## How it differs from Chat

Chat waits for you to know what to ask. Noesis starts from what you might want to discuss. It uses memory to make its suggestions personal, and the thread is an ordinary Organic LLM thread, so it carries over to the rest of the workspace.

## When to use it

Open Noesis when you have a theme in mind but not the first question. Use main Chat when you already know what you are asking.
